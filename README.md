# Page Replacement Simulator

A command-line based Operating Systems project written in C that simulates and compares different page replacement algorithms.

## Overview

When a page fault occurs and all available memory frames are occupied, the operating system needs to decide which page should be removed from memory.

This project simulates this page replacement process using different algorithms and provides statistics such as page hits and page faults.

## Planned Algorithms

The simulator will implement:

- FIFO (First-In, First-Out)
- LRU (Least Recently Used)
- Optimal Page Replacement

The project will also provide a comparison of the algorithms based on their simulation results.

## Project Goals

- Understand the concept of page replacement in Operating Systems.
- Implement page replacement algorithms in C.
- Simulate page hits and page faults.
- Display the state of memory frames during execution.
- Compare the results of different algorithms.
- Practice modular C programming and project organization.
